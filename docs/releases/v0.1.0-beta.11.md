# v0.1.0-beta.11 — consolidated workspace

Publication requested by Emanuel-Sebastian Călin on 17 October 2026. This remains an educational beta, not an approved loading computer or departure authorisation.

## Changes

Five primary destinations: Overview, Loading, Inspect, Assess, Learn. Start / open condition offers presets, an empty starting condition and saved inputs. Documented simulations are a separate read-only learning path with focus/scroll handling and a return action. Active context identifies calculation/manual/teaching/playback mode and condition; named-save tracking explicitly applies to this session.

Loading groups onboard supplies, cargo (arrangement and optional capacity), ballast and totals. Inspect prioritises the viewport and results; properties and calculation options are on demand. Assessment prioritises failed/unresolved checks and exposes graphs through expandable sections and direct links. Redundant controls and background paragraphs are reduced. EN/RO and existing route IDs retained.

No numerical methods, source tables or storage schemas changed. Existing loading plans, full-condition snapshots and recovery libraries remain available.
