Placement increased displacement from 4,000 to 4,002 t; overlapping placement was rejected. Allowance clearing, decimal entry and keyboard increment were checked. GitHub Actions repeats release checks.

No calculation formulas or storage schemas changed. Existing educational, model and redistribution limitations remain; no third-party assets added. User explicitly authorized deployment and the release naming scheme on 2026-10-17. Rollback: redeploy accepted beta.6; no data migration introduced.
