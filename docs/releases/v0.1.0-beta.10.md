# v0.1.0-beta.10 — navigation and contextual documentation

Release prepared 17 October 2026. Emanuel-Sebastian Călin explicitly requested upload and publication on this date, retaining the verification, source-data and rollback qualifications below. Exact source revision and deployment outcome are recorded separately.

The primary workflow remains Overview → Loading → 3D inspection → Assessment. Calculation tools and Learning have separate menus; portrait navigation uses the same hierarchy, with Trim & Drafts under Assessment. Supporting destinations link to their own help topics.

Condition settings groups ship selection, supplied loading conditions with preview/apply/undo, and advanced calculation settings. Save & open groups full-condition snapshots, existing loading plans and recovery, backups and report export. The two existing storage formats are preserved: snapshots retain manual inputs, while cargo plans load weight-based conditions. No storage schema migration is introduced.

Loading offers a direct route past optional capacity planning. Planner creation, selection properties and navigation are distinguished; support tasks give contextual instructions. Select/Pan and Undo/Redo remain beside the viewport. 3D inspector tabs are Appearance, Ship position and Selected item. Assessment exposes GZ, wind/rolling and securing sections and provides the securing editor without leaving the assessment.

Help has dedicated supporting-tool topics, a worked stowage-factor example, and capabilities/limitations as its first topic. The duplicate footer capabilities link is removed; the Overview summary still links to that chapter. Trim equations use subscripts and fractions. The decorative XYZ triad is removed from the Explore banner. EN/RO labels are included.
