# v0.1.0-beta.9

Cargo catalogue and theory now distinguish package types and shape variants, with standard pallet/drum/container size selections. Expanded contextual help includes original app screenshots and interactive practice. Loading navigation leads from totals to 3D inspection, with accessible saved-plan actions. Support tools include manual pieces, axis-aligned bearer drawing, gap/layer/frame tasks and round pads. 3D axes can extend across the view.

The consolidated voyage assessment combines conclusions, GZ, wind/rolling and securing graphs with snapshot reports. Weather inputs are accessible without an assessment-basis resource. The declared rectangular Pontoon weather model shares draught and corrected GM calculations; GZ and wind lines remain visible when roll/energy cannot be assessed. Vectis documented wind profiles remain available even when the current condition cannot balance. Source guidance distinguishes General Arrangement dimensions from condition-specific immersion data. No source flooding angle or empirical applicability is invented.

Verification: 602 regression tests passed during integration; final focused report/context/graph tests (7) and lint/build passed. Browser checks covered Pontoon graph/inputs and Vectis profile availability and missing-trim guidance. Release-tool, advisory and subpath checks are recorded during release preparation. Existing bundle-size warnings remain.

Limits: the Pontoon's supported draught range lies outside the IS Code empirical roll B/d range, so it cannot receive a rolling-energy pass from that method. Vectis condition-specific inputs and source coverage still constrain assessments. No overall voyage authorization, structural support approval, damage-stability or longitudinal-strength certification is claimed. Manual bearer drawing is axis-aligned; cargo geometry and wind projections remain declared approximations. No new claim of physical-device acceptance, crash recovery or complete operational validation is made.
