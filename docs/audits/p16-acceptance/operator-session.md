# Uncoached operator acceptance session

Status: not yet conducted. Do not fill results from scripted tests.

Record participant alias (no personal cargo data), date, browser/version, OS, screen size, input device, language, build revision, start/end time, and prior experience. Use a clean test profile and disposable fixture plans. The observer may explain the task goal but must not explain the controls; record every request for help before assisting.

## Give the operator these goals

1. Choose the pontoon, add twelve 1 t packages with actual dimensions, including a rotated pair; leave a deliberate ventilation gap. Correct a placement mistake, add a support, and identify its contribution to totals.
2. Adjust ballast, inspect the resulting draughts and angles, and explain any unavailable assessment result without treating it as a pass.
3. Save departure, create a changed arrival condition, compare them, export the study and a readable report. Close the browser, return, and demonstrate the saved condition. Restore the exported study in the separate test profile.
4. Repeat an appropriate smaller task with Vectis Castle and the independent imported fixture. Explain what the visual hull does and does not establish.
5. On a physical touchscreen and trackpad, select, pan, zoom, place, rotate, cancel and undo. Repeat key tasks in the other language. Use keyboard navigation without the pointer for form entry, navigation and result inspection; record any canvas-only action without an equivalent.
